Syllabus

Six months, one module a month

What you learn month by month

Each module ends with a graded project. Fail one and you repeat it with the next batch at no cost.

  1. Month 1

    Web foundations

    HTML semantics, CSS layout with flexbox and grid, Git and the command line.

  2. Month 2

    JavaScript in depth

    The DOM, events, fetch, async code and debugging in the browser.

  3. Month 3

    React

    Components, state, hooks, routing and testing with a real design system.

  4. Month 4

    Node.js and databases

    Express APIs, PostgreSQL, authentication and input validation.

  5. Month 5

    Team project

    Four-person teams build and deploy a product with weekly sprint reviews.

  6. Month 6

    Interview readiness

    Data structures practice, system design basics and mock interviews.
